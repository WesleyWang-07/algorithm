# MATLAB 移植保持 0 基坐标空间，以与 Python/专利数值逐位一致

MATLAB 惯例是 1 基索引（`ink(1,1)` 是左上角），但本移植的内部坐标 (r,c) 沿用
Python 版的 0 基约定，仅在 `is_open.m` 一处做 +1 数组下标换算；打印的四指标、
交点坐标、路径点数与 Python 版完全一致，两版结果可直接逐位对比。

**为什么**：专利用 x°=0 定义左缘初始滴点，Python 测试（test_patent 的 3×3 窗口、
demo 的交点 (64,90)）全部基于 0 基数值；若改成 1 基，所有打印数字、历史测试断言、
与论文章节的对照（如"落点 row≈95"）都要做 ±1 换算，出错概率高且无法和 Python
并排验证。代价是 `ink(r+1, c+1)` 的下标换算分散在绘图处，且未来读者可能把
0 基当疏漏"修正"——请勿修正，除非同步改 Python 与全部断言。

**备选**：1 基 + 输出时 −1；内部 0 基 + 绘图时 +1（选中项，换算只集中在边界）。
