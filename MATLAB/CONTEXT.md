# 专利滴水算法（MATLAB 移植）

把发明专利《基于水滴双向飞溅的滴水路径优化》的算法移植到 MATLAB，与 Python 版
（`../专利滴水算法实现/`）语义逐行等价、输出数值一致；目标是把古琴减字谱字
双向切分成左上/右上/下部三块子图。

## Language

**滴水算法**:
模拟水滴在二值图像白色空隙中受重力下落、沿墨迹轮廓绕行来生成字符分割路径的算法。
_Avoid_: 水滴算法、下落算法、drop-fall 的"掉字法"

**墨迹（墨像素）**:
二值图上黑色笔画像素；本项目约定 `ink=true` 为墨迹、`false` 为白色可走。
_Avoid_: 前景色、黑色（黑/白有多义性）

**空白（白像素）**:
非墨迹像素，水滴唯一可走的区域；越界按白处理（允许贴边逃逸）。

**初始滴点**:
水滴起始像素坐标 (x°, y°)，权利要求 5 四指标优化的对象。
_Avoid_: 起点、水口

**重力方向 g**:
单位方向 (dr,dc)；l1 为 (0,1) 向右、l2 为 (1,0) 向下；水滴始终优先沿 +g 前进。

**邻点窗口（n0..n7）**:
当前滴点 n0 与其 7 个邻点；权值 g_j = 8−j（S101，图1/图2）。

**重力势能 Q_i**:
Q_i = max_j(z_j·g_j·o_j)，只在白像素之间取最大值（S103）。
_Avoid_: 高度、能量（与物理势能只是类比，不是同义词）

**方向位 k**:
{−1,0,1} 记录水滴当前取向：0 初始、1 偏右(+p)、−1 偏左(−p)；遇阻随机取向产生（S102）。
_Avoid_: 方向因子、倾斜角

**方向因子 o_j**:
由 k 决定的符号调制，使非偏好一侧窗口权重变负（图3）。

**飞溅状态 s**:
{0..5} 记录浅坑内的尝试进度：0 等待飞溅、1 已飞溅 1px、2 水平反向 1 次、3=1+2、
4 反向 2 次、5=1+4。

**滴落 / 飞溅 / 回流 / 熔断**:
四种水滴动作，优先级从高到低（S103）。滴落=沿重力前进；飞溅=向"后下方"跳 1px；
回流=原位反转 k 并 s+=2；熔断=沿重力穿透 1px 墨迹（保底，越少越好）。
_Avoid_: 穿透、钻（熔断的俗称）

**浅坑**:
前方与两侧全被墨迹挡住、仅后侧有空的死锁工况；传统滴水算法在此水平往复死循环。
_Avoid_: 凹槽、死区

**四指标 A/B/C/D**:
初始滴点优化指标：A=熔断量 d、B=始末垂直起止偏移 |x*−x°|、C=累计偏移 v、
D=d+B+v 融合指标（论文实验结论 D 最优，默认使用）。

**双向切分（l1 / l2）**:
l1 为水平滴水（上下切分）+ l2 为竖直滴水（左右切分）的连续两刀；两路径的交点即
切分锚点，直接裁剪出 左上/右上/下部 三张子图，不产生冗余中间图像。

**切分锚点**:
l2 命中 l1 时的交点 (xi,yi)，三张子图裁剪的基准。

**减字符号**:
古琴减字谱的基本单位；泛音谱字结构固定 = 左上（左手指法）+ 右上（徽位）+
下部（右手指法与弦位），本算法把完整谱字切成这三个减字符号待识别。
_Avoid_: 字、偏旁（泛指时语义过宽）
