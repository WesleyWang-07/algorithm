# 08-指标 A 实验解读 —— 为什么 A 和 D 选出的起点不同

> 配套：`../专利滴水算法实现/demo_segment.py`（动手清单第 3 步：四种指标对比）
> 实验日期：2026-09-08；本文记录的是 metric='A' 的真实运行结果与逐项解读。

## 1. 当时的真实输出（metric='A'，关键行）

```
最优初始滴点 l1(横向/红色): (64, 0)   l2(纵向/绿色): (0, 63)
指标 l1(A/B/C/D): 0/0/0/0
指标 l2(A/B/C/D): 0/27/27/54
两路径交点(分割锚点): (r=64, c=90)   横长 221 竖长 91
```

对比一下（metric='D' 时）：l2 起点 **(0, 90)**，指标 **0/0/0/0**，交点同样是 (64, 90)，竖长 65。

## 2. 一句话结论

**两种指标选出了不同的起点、走了不同的路线，但终点/交点/裁出的三张子图完全相同。**

- A 版本的 l2 路线：从第 63 列落下 → 顶部撞上左边"大"块的顶面 → 沿块顶**右滑 27 格**到走廊第 90 列 → 竖直落到底 → 第 64 行踩到红线 l1，交点 (64, 90)；
- D 版本的 l2 路线：从第 90 列走廊**直落** → 交点 (64, 90)。

## 3. 逐项解释 l2 的 0/27/27/54

| 数字 | 含义 | 白话 |
|---|---|---|
| A = 0 | 熔断次数 d | 全程没烧穿任何墨迹——A 很满意 |
| B = 27 | 终点与起点在垂直重力方向的漂移 | 终点 90 列 − 起点 63 列 = 27 列 |
| C = 27 | 累计偏移（绕行步数） | 沿块顶水平滑了 27 步 |
| D = 54 | A + B + C | 融合指标 |

竖长 91 也对得上：19 步下落 + 27 步滑动 + 44 步下落 + 起点 1 = 91 个点。

## 4. 为什么 A 选中 63，D 选中 90（本轮最关键的发现）

- **A 只数熔断**：第 63 列路径 d=0，第 90 列直落 d=0，两候选在 A 上并列第一；
- 枚举代码的取舍规则（`segment.py`）：`if score < best: best = ...` —— **严格小于才更新，并列时保留先到者**。列号从小到大枚举，63 先到，于是 A 选 63；
- **D 额外记账**：D = d + B + C —— 63 的路径 0+27+27=54；90 的路径 0+0+0=0，于是 D 选 90。

一句话：**A 只看"有没有切坏笔画"，不关心"绕了多远"；D 把绕行和漂移都记了账。**

## 5. 为什么论文实验里 D 仍是最优

干净合成图上绕行无所谓（刀口相同）。真实手写谱字上，绕行常常导致绿线切进笔画、落到错误位置——A 就会选中"零熔断但切歪"的起点；D 逼路线又短又直。论文表 3-5/3-6（99.06% / 95.52% 那两组数字）就是在真实谱字集上测出来的。

## 6. 两个顺带解答的问题

- **为什么"粘连"和"无粘连"输出完全相同？** 因为这条路线从头到尾没靠近中间的粘连竖线（第 108~113 列、行 24~57）；那条线只对"恰好穿过它"的列生效。想看它熔断，可以手动把起点固定在第 110 列试一次。
- **为什么交点还是 (64, 90)？** 两条路径最后都进同一条走廊、踩到红线同一点 → 锚点相同 → 三张子图相同。区别只在绿线的"长相"（A 版本先在块顶横着滑一段再下来）。

## 7. 下一步（B / C / D 三行的先猜再跑）

- 按同样的猜测逻辑：**B 只算终点漂移**（直落漂移 0 < 绕行 27）、**C 只算绕行步数**（直落 0 < 27），所以 B、C 大概率都和 D 一样选中 (0, 90)；
- 跑完验证后，把 `demo_segment.py` 第 65 行改回 `metric='D'`（文件第 17 行注释也是这样提醒的）；
