# 第 5 课 · 枚举 + 指标选优：怎么选起点

同一个入口，从不同行滴进去，切出的线好坏不同（第 1 课的变体练习你已经见过三种命运）。
做法朴素到不像"算法"：**候选有限时，全试一遍，挑分最高的。**

## 代码模式（segment.py 的 bidirectional_segment）

```python
best = None
for r0 in r_span:                          # 只试中间带 δ1 ∈ (2/5·N, 3/5·N)
    res = drop_improved(ink, r0, 0, g)     # 真滴一次
    score = path_metrics(res, g)['D']      # 给这条路径打分
    if best is None or score < best[0]:    # 分数越低越好
        best = (score, r0, res)            # 记住目前最好的
```

为什么只在**中间带**试？因为切口理应从图像中部通过——这是论文 3.4 节用实验定出的范围：
上下切分 δ1 ∈ (2/5·N, 3/5·N)，左右切分 δ2 ∈ (2/7·M, 3/5·M)。

## 四个指标打什么分（专利权利要求 5）

| 指标 | 最小化目标 | 通俗理解 |
|---|---|---|
| A | 熔断量 d | 一路烧穿了几格墨迹——像抄近道踩坏了几块草皮，越少越好 |
| B | 始末偏移 \|x\*−x°\| | 终点相对起点跑偏多远——越直越好 |
| C | 累计偏移 v | 全程"没顺着重力走"的步数——拐弯越少越好 |
| **D** | d + \|x\*−x°\| + v | 三项相加，**论文实验证明综合最优，代码默认用它** |

论文的成绩单（表 3-5 / 3-6）：D 指标在无粘连谱字集切分成功率 **99.06%**、
粘连谱字集 **95.53%**，都明显高于传统滴水算法（93.45% / 83.70%）和投影法（53.27% / 不适用）。

## 为什么这算"搜索思想"

它是最基础的**枚举搜索**：解空间有限 → 逐个尝试 → 用评估函数打分 → 保留最优。
以后你会遇到的"网格搜索调超参数""暴力匹配"，全是同一个套路。
