## 1. 变量 —— 贴了名字的盒子

```python
H, W = ink.shape        # segment.py：把图像的"高、宽"两个数装进两个盒子
r, c = r0, c0           # improved_droplet.py：水滴当前位置
```

## 2. if / elif —— 逐条检查规则

"满足哪条执行哪条，都不满足就走 else"。传统滴水算法的 6 条规则写出来就是最朴素的
if/elif 链（本课末尾的练习脚本就是完整实现）。

## 3. for / while —— 重复做

水滴的整个旅程就是一个循环：每圈走一步，直到流出边界。

```python
for step_i in range(max_steps):     # improved_droplet.py 主循环
    ...
    if r < 0 or r >= H or c < 0 or c >= W:
        break                        # 走出图像，旅程结束
```

## 4. 列表（list）—— 有序的格子序列

水滴走过的轨迹就是一个列表，每个元素是一个 `(行, 列)` 坐标：

```python
path = [(2, 1), (2, 2), (2, 3), ...]
```

## 5. 字典（dict）—— 贴标签的储物柜

```python
_G7 = {j: 8 - j for j in range(1, 8)}   # 邻点编号 → 权重：{1:7, 2:6, ..., 7:1}
metrics = {'A': 0, 'B': 0, 'C': 0, 'D': 0}   # 四指标成绩单
```

## 6. 函数 —— 打包好的动作

```python
def is_open(ink, r, c):
    """(r,c) 是不是白色可走？越界按白处理（允许水滴贴边逃逸）。"""
    H, W = ink.shape
    if r < 0 or c < 0 or r >= H or c >= W:
        return True
    return not ink[r, c]
```

写一次，到处用——`_q_decision` 每步要问 7 次"邻点白不白"，全靠它。

## 动手实验：亲眼看到"浅坑死锁"

运行本目录的 [练习-mini_drop.py](练习-mini_drop.py)（传统 6 规则水滴，0=白可走，1=黑墨迹）。

**预期现象**：水滴前几步顺利下滑，掉进 `(2,2)` 和 `(2,3)` 构成的浅坑后，
在两格之间**来回打转直到步数用光**。这不是程序 bug，是这 6 条规则真的无解——
专利的全部意义就是救这个局（见 [04-状态机思想.md](04-状态机思想.md)）。

**变体练习**：
- 起点改成 `c = 1`：水滴从左墙内侧掉进坑，同样卡死；
- 起点改成 `c = 3`：水滴从坑右侧绕出去，顺利到达底部。

三种起点三种命运——这也解释了论文为什么要专门研究"初始滴点怎么选"（第 5 课）。
