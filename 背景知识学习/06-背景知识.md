# 第 6 课 · 背景知识：古琴减字谱 + 怎么读这份专利

## 1. 古琴减字谱为什么长那样

古琴谱用"减字谱"记谱：把汉字削减笔画后拼成一个**谱字**，记录"左手按哪、右手怎么弹"。
泛音段谱字是固定的**上下结构**：

```
┌─────────┬─────────┐
│ 左上：   │ 右上：   │   左上 = 左手指法（大指"大"、食指"亻"、中指"中"、名指"夕"）
│ 左手指法 │ 徽位数字  │   右上 = 徽位（一 ~ 十三）
├─────────┴─────────┤   下   = 右手指法（托擘挑抹剔勾打摘）+ 弦位（一 ~ 七）
│      下：          │
│ 右手指法 + 弦位     │   例：项目里那张真实谱字 = 大 + 七 + 勾
└───────────────────┘        读作"大指在七徽勾弦"
```

**为什么要先切分再识别？** 完整谱字有三千多种，直接认需要天文数字的样本；
而拆成零件后只有 **82 类**（论文自建数据集：139 人手写、清洗后 11311 张样本）。
**先拆零件 → 认零件（CNN，准确率 96.75%）→ 按结构组装成语意**——样本量从"不可能"变成"可行"。
切分正是这条流水线的第一环，切坏了后面全错（论文表 4-4：切分错误子图的识别率只有 60.34%）。
