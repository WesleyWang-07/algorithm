# 10-怎么读 segment.py —— 编排层代码的读法

> 配套：`../专利滴水算法实现/segment.py`；前提：09（决策层）已读；本课时长约 40 分钟
> 一句话：决策层回答"水滴**下一步怎么走**"，编排层回答"**从哪滴、滴几刀、怎么裁**"。
> 本课教的三步法可迁移到任何"编排/调度"型文件（包括 `run_real.py`）。

## 0. 先立方法：读编排层的三步法

### 第 1 步 看接口（函数对外承诺什么）

| 函数 | 输入 | 输出 |
|---|---|---|
| `build_synthetic_character(H,W,connect_top)` | 尺寸、要不要加粘连竖线 | `ink`（H×W 布尔图，True=墨迹） |
| `bidirectional_segment(ink, metric, metric2, seed)` | 一张二值图、**l1 的指标**、**l2 的指标**、随机种子 | `l1_path/l2_path`、`intersect`、`crops`（三张子图）、`metrics1/2`、`start1/2` |

> **注意有两个指标参数**（2026-09-17 阶段三改动）：`metric` 管 l1（默认 `'D'`）、
> `metric2` 管 l2（默认 `'B'`）。此前只有一个 `metric`，两刀共用；
> 为什么拆开：论文表3-1 显示粘连谱字只有指标 B 能同时切对上下与左右。

**先记住返回值**：读正文时每个变量你知道它最后会变成哪个字段，就不会迷路。

### 第 2 步 追数据流（全文件就一条主线）

```
build_synthetic_character ──ink──┐
                                 ▼
   l1 枚举（r0 在 δ1 带内）──► l1_path ──► l1_set（红线所有格点）
                                              │ 作为 terminate_at
                                              ▼
   l2 枚举（c0 在 δ2 带内）──► l2_path ──► (xi, yi) 交点
                                              │
                                              ▼
                        crops = left_top / right_top / bottom
```

一句话复述：**枚举起点 → 各滴一条路径 → 按指标挑最好 → 第二刀踩红线停 → 交点裁三块。**

### 第 3 步 认模式 + 标危险点

编排层反复出现两个模式，认出它们，代码就不再是一行行读：

- **模式 A「枚举 + 打分选优」**：`for 候选 → 跑一遍 → 算指标 → 严格更小才更新`（l1、l2 各一遍）；
- **模式 B「入口过滤 + 兜底」**：`is_open` 不对就 `continue`；一个候选都没有时回退带中点。

同时标出三个**危险点**（读任何图像代码都要警惕）：

1. **坐标基**：本文件全是 0 基，没有一处 `+1`（和 MATLAB 版相反）；
2. **切片右开区间**：`ink[0:xi, 0:yi]` 不含 `xi` 行、`yi` 列；
3. **并列最优**：`score < best` 是严格小于 → 并列时**保留先到者**。

## 2. 逐段拆解

### 2.1 `build_synthetic_character`（27~49 行）——先读它

它是"输入长什么样"的说明书，读懂了后面裁剪才有着落：

- `blob(r0,r1,c0,c1)` 是个内部小函数，作用就是 `ink[r0:r1, c0:c1] = True`（**右开区间**）；
- 三块墨：左上（20~57 行、22~89 列）、右上（20~57 行、132~197 列）、下部（92~137 行、28~191 列）；
- `connect_top=True` 时在 24~57 行、108~113 列加一条**粘连竖线**——它的唯一目的是给第二刀
  制造难题（考验飞溅/熔断），所以"粘连"和"无粘连"两张图会走出不同路径。

### 2.2 第 0 段：校验与随机源（77~84 行）

```python
for name, mt in (('metric', metric), ('metric2', metric2)):
    if mt not in ('A', 'B', 'C', 'D'):
        raise ValueError(...)

def make_rng(pos):
    """seed=None -> 确定性枚举（不取向）；否则该候选的独立固定随机源。"""
    return None if seed is None else np.random.default_rng(seed + pos)
```

- 白名单**两个参数各查一遍**，并把参数名 `name` 带进报错信息，方便定位是哪个传错了；
- **`seed` 默认 `None` = 确定性枚举**（2026-09-17 阶段三改动）——此前是 `seed=20241016` 固定。
  为什么要改：候选之间要比指标，就要求每条路径可复现；若各候选共享一个随机流，
  前一个候选抽过的随机数会影响后一个，比较就不公平了。
- `make_rng(pos)` 用 `seed + pos` 给**每个候选独立的固定种子**，而不是共享一个——
  这就是上面那句话的实现。传 `None` 时直接不取向（S102 关闭）。
  **为什么需要随机源**：见 `improved_droplet.py` 第 208~213 行，遇浅坑才定 k。

### 2.3 第 1 段：l1 枚举（86~101 行）——模式 A + 模式 B

```python
n1 = int(round(0.4 * H)); n2 = int(round(0.6 * H))
r_span = list(range(max(1, n1), min(H - 1, n2)))   # δ1 带
...
for r0 in r_span:
    if not is_open(ink, r0, 0):      # 入口是墨就跳过（模式 B）
        continue
    res = drop_improved(ink, r0, 0, g1, rng=make_rng(r0))
    m = path_metrics(res, g1)
    if best1 is None or score < best1[0]:    # 严格小于 → 保留先到者
        best1 = (score, r0, res, m)
```

- **δ1 带从哪来**：论文 3.4 节，上下切分起点限定在高度中部 `(2N/5, 3N/5)`；`max(1,·)`/`min(H-1,·)`
  保证起点在图像**内部**（不贴边、不下一步出界）；
- `c0=0` 写死：第一刀固定从**左缘**进屋，只枚举行；
- `score = m[metric]`：`metric` 在这里从字符串变成"取哪个字段"，四个指标共用这一段代码。

### 2.4 第 2 段：l2 枚举（113~132 行）

与 l1 结构相同，**四处**不同：

1. δ2 带按**宽度**算（`w1=2W/7, w2=3W/5`，第 115 行），起点固定在上缘（`r=0`），枚举列 `c0`；
2. `drop_improved(..., terminate_at=l1_set)`：把第一刀所有格点做成集合传进去，水滴踩到就停
   （`l1_set = set(l1_path)`，第 111 行）——**这是两刀产生交点的机制**；
3. **用的是 `metric2` 不是 `metric`**（第 124~125 行 `m[metric2] < best2[0]`）——
   这是两刀唯一"不是简单复制"的地方，别读成同一段代码复制了两遍；
4. 兜底同样存在（`best2 is None` → 回退带中点）。

### 2.5 第 3 段：求交点（134~138 行）

```python
if res2['stopped_by'] == 'terminate_at':
    xi, yi = l2_path[-1]     # 踩红线停的，最后一点就是交点
else:
    xi, yi = res2['end']     # 没碰到红线（异常情况），退回用终点
```

读法：先看 `drop_improved` 的返回值约定（`stopped_by` 三种取值），这里只是**消费**这个约定。

### 2.6 第 4 段：裁剪（140~147 行）——危险点 2 现场

```python
xi = min(max(xi, 0), H - 1);  yi = min(max(yi, 0), W - 1)   # clamp 防越界
crops = {
    'left_top':  ink[0:xi, 0:yi],
    'right_top': ink[0:xi, yi:W],
    'bottom':    ink[xi:H, 0:W],
}
```

**为什么这样切片正好**（自己验证一遍，比背下来强）：三块是
`[0,xi)×[0,yi)`、`[0,xi)×[yi,W)`、`[xi,H)×[0,W)`——**互不重叠、合起来正好铺满全图**。
`xi` 行归下部，`yi` 列归右上。改任何一处右端点都会多算/漏算一行一列。

### 2.7 第 5 段：返回（149~158 行）

把两条路径、交点、三块、两套指标、两个起点打包成 dict。读到这可以回头对第 1 步的"接口表"，
确认每个字段都出现在下面的脚本里（`demo_segment.py` 打印指标，`run_real.py` 拿 `crops` 做 IoU）。

## 3. 三处"将来要改的地方"（精读到能改才算过关）

> **行号基准**：以下行号按 2026-09-17 之后的 `segment.py`。阶段三改动（拆出 `metric2`、
> `seed` 默认改 `None`、加 `make_rng`）让全文件整体下移了十几行，**旧讲义的行号已全部作废**。

| 位置 | 现状 | 如果改了会怎样 |
|---|---|---|
| **tie-break**：第 99 / 124 行 `score < best` | 并列最优**保留先到者** | 改成 `<=` 会保留**最后到者**：合成图上 l2 起点会从 (0,90) 变成同分候选中最后那列 |
| **切片边界**：第 141~146 行 | 右开区间，三块无缝铺满 | 把 `left_top` 写成 `ink[0:xi+1, 0:yi]` 会多带一行墨进左上 |
| **兜底**：第 101~105 / 126~130 行 | 带内入口全被墨挡时回退带中点 | 删掉兜底，遇到黑边框/污渍图会直接 `TypeError`（`best1` 是 `None`） |

再加一条**全局危险点**：本文件坐标全 0 基，切片、打印、断言口径一致；MATLAB 版的 `+1` 换算
只藏在 `is_open.m` 里——两边对照时别把 `+1` 抄到 Python 这边来。

> **还有一处"将来要改的地方"值得知道**（2026-09-17 三次复核新增）：l2 的选优指标 `metric2='B'`
> 决定了它的语义是"**允许路径不落在真值附近，只要贴合自己的起点**"。真实谱字上它给出
> 锚点 col 46（`x_rel = 0.313`），比指标 D 的 col 44 只差 2 列——**这条指标在本图上的
> 分辨力其实很弱**。若将来要改 l2 的选优逻辑，先想清楚"你到底想让它优化什么"；
> 详见 `../专利滴水算法实现/验证报告.md` 的 4.7 节（那里论证了"复现论文图3-23"这个目标本身不成立）。

## 6. 自查（先做，答案在文末）

- Q1：l2 的候选循环里为什么要传 `terminate_at=l1_set`？不传会怎样？
- Q2：`ink[0:xi, yi:W]` 里 `yi` 这一列算进左上还是右上？交点所在的 `xi` 行算进哪块？三块会不会重叠或漏掉？
- Q3：指标 A 时 l2 选中 (0,63) 而不是 (0,90)，是哪一行代码决定的？改成 `<=` 会怎样？
- Q4：`r_span` 为什么要写成 `range(max(1,n1), min(H-1,n2))`，而不是直接 `range(n1,n2)`？
- Q5（新增）：`metric` 和 `metric2` 为什么要分成两个参数？如果 l2 也用 `metric`（D 指标），
  真实谱字上的锚点会变成哪一列？

---

**自查答案**：

1. 不传的话第二刀不会在上半区停下，会继续往下穿/绕下部墨块，终点就不再是两刀交点；
   用这个终点去裁三块会失去"左上/右上/下部"的语义（第二刀的本意只是分左右上）。
2. `yi` 列归**右上**（左上切片 `0:yi` 右开、不含 `yi`）；`xi` 行归**下部**（左上/右上切片 `0:xi`
   不含 `xi`）。三块互不重叠且合起来正好是全图，没有重叠也没有遗漏。
3. 决定在**第 124 行** `if best2 is None or m[metric2] < best2[0]`（l1 是第 99 行同款）。
   改成 `<=` 就变成"后来的并列者覆盖先到的"，指标 A 会选到某个 A=0 的靠后候选，起点对不上
   第 3 步的记录；D 指标下若没有并列，结果不变。
4. 两层保险：`max(1,·)`/`min(H-1,·)` 让候选落在图像**内部**——不取第 0 行（贴边）、不取最后一行
   （下一步就出界），极小图时也不会产生越界范围；`range()` 再右开一层，确保 `r0 ≤ H-2`。
   注意全程 0 基，没有 `+1`。
5. 因为两刀要优化的东西不同：l1 分上下，偏移/熔断都敏感，论文结论 D（融合）最稳；
   l2 分左右，论文表3-1 显示**粘连谱字只有 B 能同时切对上下与左右**。
   若 l2 也用 D，实测真实谱字上锚点会变成 **col 44**（`x_rel = 0.298`），
   而用 B 是 **col 46**（0.313）——**两者只差 2 列**。这个微小的差别说明：
   在这张图上指标的分辨力很弱，`metric2` 的选择并不像想象中那么关键。
