# 背景知识学习手册（滴水算法项目）

> 配套项目：`../专利滴水算法实现/`（改进滴水算法的 Python 实现）
> 适用读者：零基础。全部示例都来自项目真实代码，建议学到哪课就动手试到哪课。

## 一张总览图

整个项目只干一件事：**在一张由小方格组成的黑白图上，让一滴虚拟的水从边缘流过去，
它走过的路线就是切分线。** 下面所有课程，都是为了让你读懂"水怎么走"这四个字背后的代码。

## 动手清单（学完全部后按顺序做一遍）

1. **跑**：进入 `../专利滴水算法实现/` 目录运行 `python demo_segment.py`，
   打开 `output/overlay_无粘连.png`，亲眼看到红线（上下切）绿线（左右切）。
2. **玩**：运行本目录的 [练习-mini_drop.py](练习-mini_drop.py)，亲眼看传统算法的"浅坑死锁"；
   再把起点 `c = 2` 改成 `1` 和 `3`，对比三种命运。
3. **改**：把 `demo_segment.py` 里 `metric='D'` 改成 `'A'`/`'B'`/`'C'` 各跑一次，
   对比控制台里选中的初始滴点和指标值。
4. **读**：左手专利图4~图12（`../文献/patent_pages/page_05.png` ~ `page_07.png`），
   右手 `improved_droplet.py` 的 `_q_decision` / `_step_patent`，逐格对照。
5. **系统补语法**：Python 官方中文教程 docs.python.org/zh-cn/3/tutorial；
   numpy 入门搜 "numpy quickstart"。

> 卡在哪一课、哪个报错，把现象发出来，逐行看。
