# 第 2 课 · 图像的基本概念

## 1. 二值图像 = 0/1 大表格

把黑白图放大到极限，每个小方格（**像素**）只有黑或白两种。项目里的约定：

- `ink[r, c] == True` → 第 `r` 行第 `c` 列是**黑墨迹**（走不了）
- `ink[r, c] == False` → **白色可走**

坐标约定：`r` 从上往下数，`c` 从左往右数。这和专利里"x 轴正方向竖直向下、
y 轴正方向水平向右"（图4）是同一个约定，只是换了字母。

## 2. 3×3 邻域 —— 全项目的核心图

水滴每走一步只看周围一圈。一圈本来 8 格，专利把"正后方"那格砍掉
（水滴受重力向前，不回头），剩 7 格，编号 j=1~7，权重 `g_j = 8 − j`：

```
n7(权1)   ·       n6(权2)      ·  = 正后方，不参与
n5(权3)   n0      n4(权4)      n0 = 水滴当前位置
n3(权5)   n1(权7) n2(权6)      权重含义：越"顺着重力"分越高
```

（此图对重力方向 g=(1,0) 竖直向下成立；项目里 `perp_of(g)` 把它推广到任意方向。）

**专利的图4~图12，全部是这张小棋盘上"哪几格白、哪几格黑"的不同摆法。**
看懂这一张图，专利就看懂了一大半。

## 3. Pillow —— 只干两件事

**读图**（`run_real.py` 的 `load_ink`）：打开图片 → 转数组 → "红绿蓝三个通道都暗
才算墨迹"。这样论文图里的红色标注线（R 通道亮）就被自动排除了：

```python
im = Image.open(path).convert('RGB')
a = np.array(im).astype(int)
ink = (a[..., 0] < thresh) & (a[..., 1] < thresh) & (a[..., 2] < thresh)
```

**存图**（`demo_segment.py` 的 `ink_to_image`）：`True(墨)→0(黑)`、`False→255(白)`，
转回图片保存。

## 4. Otsu 二值化 —— 知道这句话就行

Otsu（大津法）会**自动**找一个灰度阈值把扫描照片切成纯黑白，不用人手动调。
论文 3.1.2 节用的就是它。项目演示用合成图，所以代码里看不到它；
处理真实谱字照片时才需要（论文 3.1 节的预处理流程：灰度化 → Otsu 二值化 → 去白边）。
