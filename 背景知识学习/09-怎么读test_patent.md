## 1. Q 是什么（本课门槛，务必先过这一节）

### 1.1 Q 的身份：每一步现算的"出口评分"

水滴滴到某一格、准备迈下一步时，代码要回答"往哪走"。它把周围 7 个邻点挨个看一遍，
**只给白格打分**，然后取最高分，这个最高分就是 **Q**：

```
Q_i = max ( z_j · g_j · o_j )        j = 1..7
```

下标 `i` 表示"第 i 步"——Q 是**每走一步重新算一次**的量，不是累计值（累计的是 s 和偏移量）。
专利把它叫"重力势能"，只是类比（水往低处流），实际就是一张加权评分表，别当成物理能量。

### 1.2 三个乘数各是什么

| 符号 | 叫什么 | 取值 | 通俗理解 |
|---|---|---|---|
| `z_j` | 像素值 | 白格 1、黑格 0 | 黑格分数直接变 0，等于被踢出比较——墙不能走 |
| `g_j` | 方向权值 | `8 − j`（j=1→7，j=2→6 … j=7→1） | **越顺重力方向分数越高**：正前方 7 分最高，身后 1 分最低 |
| `o_j` | 方向因子 | `+1` 或 `−1` | 由方向位 `k` 决定：把"非偏好一侧"的分数**变成负数** |

一句话：**`g_j` 管"这个出口顺不顺路"，`o_j` 管"这个出口是不是我想去的方向"。**

### 1.3 一次算给你看

**例 1**：`make({1})`、k=0（图4 的场景，只有正下方是白的）

- j=1：g=7，o=+1（k=0 时全是 +1）→ 7
- 其余六格全黑 → 0（被跳过）
- **Q = 7** → 表里 Q=7 对应"滴落"→ 向下走。

**例 2**：`make({5, 3, 7})`、k=1（图12 的场景，只有左边三格是白的）

- j=3（左下）：g=5，o=(−1)³=−1 → **−5**
- j=5（左边）：g=3，o=(−1)⁵=−1 → **−3**
- j=7（左上）：g=1，o=(−1)⁷=−1 → **−1**
- **Q = −1 < 0** → 表里 Q<0 对应"回流"：原地掉头（k 反转）。

### 1.4 Q 值决策表（专利图4~图12 就是这张表）

| Q | 含义 | 动作 | 对应图 |
|---|---|---|---|
| **7** | 正前方白 | 滴落（向下走） | 图4 |
| **6 / 5** | 前对角白（右/左） | 斜着滴落 | 图5 / 图6 |
| **4 / 3** | 侧面白（右/左） | 横向滑动 | 图7 / 图8 |
| **2 / 1** | 浅坑：只有"后方"白 | 飞溅（向后跳 1 格） | 图9 / 图10 |
| **0** | 七格全黑，没有出口 | 熔断（向前穿透 1 格墨迹） | 图11 |
| **< 0** | 有白格，但只剩"非偏好那侧" | 回流（原地、k 反转、s+2） | 图12 |

### 1.5 三个最容易混的点

1. **为什么 Q=0 和 Q<0 要分开？** Q=0 是"一个白格都没有"（真没路 → 熔断）；
   Q<0 是"路是有的，但全在我想法的反面"（被顶回来了 → 掉头重试）。两者动作完全不同。
2. **为什么只在白格之间取 max？** 黑格是墙。如果让黑格参与，`z_j=0` 会算出一堆 0 分，
   跟"没有出口"混在一起；跳过黑格，才能让 Q=0 干净地表示"全黑"。
3. **Q、k、s 谁是记忆？** 只有 k 和 s 是记忆：k 记住"我现在偏向哪边"，
   s 记住"这个浅坑里我已经挣扎了几次"。**Q 没有记忆**，每一步重新算。

### 1.6 一个漂亮的副产品：Q 的数值本身就编码了"哪个方向"

因为 7 个权值是 7,6,5,4,3,2,1 互不相同，乘上 ±1 之后**任意两个格子的分数都不会撞车**。
所以拿到 Q 的数值，就能唯一反推出"是哪个邻点、当前取向 k 是几"——这正是专利能用一张
"Q → 动作"表（图4~图12）取代一堆文字规则的原因。例如 Q=6 只可能来自 j=2 且 o=+1，
而 o₂=+1 要求 k=1——所以专利写"Q=6 时说明 k=1"。

## 2. 骨架（十一段断言是同一个模板抄了十一遍）

```python
_ink = make({...})                   # ① 造场景：5×5 窗口里只留这几个邻点是白的
nb, Q, a = action(_ink, k=?, s=?)    # ② 提问：这种情况下代码打算怎么走
ok(断言, 说明文字, 期望值)            # ③ 记分：成立打印 PASS，不成立打印 FAIL + 期望值
```

**关键领悟**：十一条之间只有两样东西在变——`make({...})` 留哪几个白格、`action(k=?, s=?)`
当前的取向与飞溅状态。其余每个字符都一样。读这类测试：**先找不变的骨架，再找每条变的参数。**

## 4. 三个函数各管一件事

- **`make(open_cells)`（13~20 行）——摆场景**：先把 7 个邻点全涂黑（`True`=墨迹），
  再把 `open_cells` 里列的点留白。`make({1})` = "只有正下方白"；`make(set())` = "七个全黑"。
- **`action(ink, k, s=0)`（23~26 行）——提问**：第一行问势能（拿到胜出邻点 `j` 和 `Q`），
  第二行问动作（拿到动作元组 `a`），两个都返回。
- **`ok(...)`（29~32 行）——记分**：条件真就 PASS，假就 FAIL 并把"期望"打出来。

## 5. 最碍眼的那串 `a[0]…a[4]`

`a` 是 `_step_patent` 返回的元组 `('move', 新行, 新列, 新k, 新s)`，位置含义固定：

| 下标 | 含义 | 例子 |
|---|---|---|
| `a[0]` | 动作名：`'move'` 走 / `'reflow'` 回流 / `'melt'` 熔断 | `a[0] == 'move'` |
| `a[1]` | 走完后的行 r（0 基） | 第 1 条 `a[1] + 0 == 3`：从 2 走到 3 |
| `a[2]` | 走完后的列 c | 第 1 条 `a[2] == 2`：列不变 |
| `a[3]` | 新的方向位 k | 第 7 条 `a[3] == -1`：k 取反了 |
| `a[4]` | 新的飞溅状态 s | 第 6 条 `a[4] == 1`：s 从 0 变 1 |

两个小提示：① `a[1] + 0 == 3` 里的 `+0` 没意义，当 `a[1] == 3` 读；② 第 8 条只查
`a[0] == 'melt'`，因为熔断不关心走完在哪。回流时 `a[1],a[2]` 是"原地"坐标。

## 6. 示范读两条

**第 1 条（图4）**

```python
_ink = make({1})            # 只有正下方是白的
nb, Q, a = action(_ink, k=0)
ok(a[0]=='move' and a[1]+0==3 and a[2]==2, ...)
```
读作："给我一个只有正下方开口的窗口，k=0 会怎么走？"→ Q=7 → 向下走一格到 (3,2) → 图4 的**滴落**。

**第 10 条（图12，最绕的一条）**

```python
_ink = make({5, 3, 7})      # 只留左侧三个（左下、左、左上）
nb, Q, a = action(_ink, k=1)
ok(Q < 0 and a[0]=='reflow' and a[3]==-1, ...)
```
读作："k=1 偏右，可右边全黑、只有左边三格白，会怎样？"→ 左侧权值被 `o_j` 变成负数 →
Q=−1 < 0 → 原地回流、k 反转为 −1 → 图12。

## 10. 自查（先做，答案在文末）

- Q1：`make({4})`、k=1 时 Q 等于几？为什么会走到 (2,3) 而不是 (3,2)？
- Q2：如果某条断言写成 `a[1] == 4 and a[2] == 2`，说明水滴做了什么？
- Q3：为什么 `make(set())` 那一条能测出 `Q == 0`？它和 Q<0 有什么本质区别？

---

**自查答案**：
1. Q=4。j=4（右侧，g=4）与 k=1 时的 o₄=(−1)⁴=+1 → 4 分；正下方 (3,2) 是黑的（不在
   `{4}` 里）所以没分。4 分高于左/后各格，于是沿右侧滑动到 (2,3)——图7。
2. 从中心 (2,2) 走到 (4,2)，沿重力方向向下 2 格（"滴落/前进"）。
3. `set()` 是空集合 → 七个邻点全被涂黑 → 没有任何白格参与取最大值 → Q=0（无出口，熔断）；
   Q<0 则是"白格存在、但全在非偏好一侧"（有路但方向不对，回流掉头）。一个表示"没路"，
   一个表示"路在反面"。
