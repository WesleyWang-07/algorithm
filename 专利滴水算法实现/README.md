## 1. 你在做什么（任务背景）

老师给了一张用**改进前的前身算法**做出来的样例图：对某个字做了两次分割
（第一次红色横线分上下、第二次绿色竖线分左右），要求你们把**专利里改进后的滴水算法**
用 Python 或 MATLAB 实现出来。

滴水算法（Drop-fall / Water-fall）是一种**粘连字符切分**算法：想象中的"水滴"
沿二值图像的白色空隙下滑，遇到黑色笔画就沿着轮廓"绕行"，走出来的轨迹就是分割线。
专利对它做了三处改进，让它更准、更省（少"熔断"）：
**飞溅(splash)**、**回流(reflow)**、以及**初始滴点的四种优化指标**。

---

## 2. 算法原理

### 2.1 传统滴水算法（前身，6 条优先级）

水滴受"重力"向下滴，依次尝试（论文 2.2.2 节）：

| 优先级 | 判断 | 动作 |
| --- | --- | --- |
| 1 | 正下方为白 | 向下滴落 |
| 2 | 右下方为白 | 向右下滑 |
| 3 | 左下方为白 | 向左下滑 |
| 4 | 右侧为白 | 水平向右 |
| 5 | 左侧为白 | 水平向左 |
| 6 | 全为黑 | 向下"熔断"（穿透 1 像素墨迹） |

**缺陷**：遇到"浅坑"（前方与两侧都被挡）会在水平像素间往复死循环；分割结果对初始滴点极敏感。

### 2.2 专利改进：优先级重排 + 势能化

专利把动作做成"权重——势能"的形式，并确定整体优先级：

```
优先级（从高到低）：  滴落(drop)  >  飞溅(splash)  >  回流(reflow)  >  熔断(melt)
```

- **势能**：`Q_i = max_j ( z_j · g_j · θ_j )`（专利权利要求 2/3）
  - `z_j`：第 j 个邻域像素值，**0=黑、1=白**（本文代码用布尔 `ink`：`True=黑墨迹`）
  - `g_j = 8 - j`：方向权重（越"顺"重力方向权重越高，`Q=7` 即正方向是白）
  - `θ_j`：按**方向取向状态 k** 做的符号调制，让水滴"记住"自己往哪边走、避免左右乱摆
- **方向状态** `k ∈ {-1,0,1}`：`0` 初始、`1` 偏好右侧、`-1` 偏好左侧
- **飞溅状态** `s ∈ {0…5}`：记录"浅坑"里飞溅/回流的次数

**Q_i 值与动作（专利图 4~图 11，本文代码即此决策表）**：

| Q_i | 含义 | 动作 |
| --- | --- | --- |
| 7 | 正方向是白 | 沿重力方向滴落 |
| 6 | 右对角是白（k=1） | 向"右对角"滑 |
| 5 | 左对角是白（k=-1） | 向"左对角"滑 |
| 4 | 右侧是白 | 沿右侧滑 |
| 3 | 左侧是白 | 沿左侧滑 |
| 2 | 浅坑（前+两侧被挡，上方有白） | **飞溅**：跳 1 像素反重力方向 |
| 0 | 全黑 | **熔断**：沿重力方向穿透 1 像素 |
| <0 | 只在"反方向"有白 | **回流**：反转方向取向 k 重试 |

> **说明**：专利把决策写成单个势能 `Q_i`（在 7 邻域上按 `g_j·θ_j` 加权取最大）。
> 本实现用**显式的优先级规则**复现**完全相同的决策表**——两者在行为上等价，后者更直观、
> 也易于移植到 MATLAB。图 1/2 中 `n1…n7` 的精确空间编号已在代码里化为等价的方向判定。

### 2.3 改进点为什么有效

- **飞溅**：水滴落入"浅坑"（两侧 + 前方都被挡），传统算法要么死锁要么强熔断；
  改进后先"向上跳 1 像素"，往往能跳出浅坑继续绕行，从而**减少熔断（少破坏笔画）**。
- **回流**：检测到水平方向往复循环时，反转 k（掉头），打破死锁。
- **熔断**：只在实在无路可走时沿重力方向穿透 1 像素墨迹，作为保底。

## 3. 四指标初始滴点优化（权利要求 5）

不同初始滴点得到的路径不同。专利设计了 4 个指标，在中间带内枚举初始点并选最小的：

| 指标 | 最小化目标 | 定义 |
| --- | --- | --- |
| **A** | 熔断量 | `d` 路径熔断墨迹的总次数 |
| **B** | 始末偏移量 | `|x* - x°|` 终点与起点在重力方向上的偏差 |
| **C** | 累计偏移量 | `v` 路径非直线上升那部分的总步数 |
| **D** | **融合指标** | `d + |x* - x°| + v`（论文结论 **D 最优**，默认使用） |

初始点搜索范围（论文 3.4 节）：
- 上下切分（第一刀 l1）：`δ1 ∈ (2/5·N, 3/5·N)`，N 为图像高度
- 左右切分（第二刀 l2）：`δ2 ∈ (2/7·M, 3/5·M)`，M 为上区宽度

---

## 4. 双向切分流程（论文 3.3.2、专利对应用）—— 这就是老师那张红/绿线

1. **第一刀 `l1`（红色，横向）**：重力方向设为 `(0,1)`（向左→右滑）。水滴从**图像左缘中部**滴落、向右滑，走出一条大致水平的线，把**上部（左上+右上）与下部**切开。
2. **第二刀 `l2`（绿色，纵向）**：重力方向设为 `(1,0)`（向下滑）。水滴从**上区上缘中部**滴落、向下滑，把**左上与右上**切开；**碰到 `l1` 即终止**（两路径交点 = 分割锚点）。
3. 依据交点（路径最大/最小坐标），直接裁剪出**左上 / 右上 / 下部**三张子图。


关键接口：

```python
from improved_droplet import drop_improved, path_metrics
res = drop_improved(ink, r0=64, c0=0, g=(0,1))   # 一次"横向"滴水
path_metrics(res, g=(0,1))                         # {'A':d,'B':…,'C':v,'D':…}

from segment import build_synthetic_character, bidirectional_segment
ink = build_synthetic_character(connect_top=True)
seg = bidirectional_segment(ink, metric='D')       # 双向切分，D 指标
```

`ink` 是 `H×W` 的布尔数组：`True`=黑色墨迹，`False`=白色可走。坐标约定 `(r,c)`，`r` 竖直、`c` 水平，重力方向 `g=(1,0)` 向下、`(0,1)` 向右。

## 6. 演示结果

对构造的"仿泛音谱字"（左上部件 + 右上部件 + 下部部件，可选加一条粘连竖线）：

- `output/overlay_粘连.png`：原始图叠加 **红色 l1（上下切分）+ 绿色 l2（左右切分）**
- `output/crop_left_top_*.png` / `crop_right_top_*.png` / `crop_bottom_*.png`：三张子图
- 两种情形融合指标 D 均自动选中两刀初始点，交点 (r=64, c=90)，**熔断=0**（干净切开）
- 严苛用例（上下墨迹用 1px 竖线**完全相连**）：l1 熔断 2 次、偏移 7 步仍能切过，
  **无死循环、无越界**（`test.py` 复现）

> 想换成真实古琴谱字，只需把 `ink` 换成你的二值谱字图（灰度→Otsu 二值化→去白边），
> 再调用 `bidirectional_segment(ink)` 即可。
