# diagnostics/ — 诊断脚本

> 这些脚本**不被任何代码 import**，全部手工运行，用于"看清算法在某张图上的实际行为"。
> 它们产出的结论都写进了 `../验证报告.md`，本目录保留可复跑的原始证据。

## 运行方式

```bash
cd 专利滴水算法实现/diagnostics
python diag_l2_trace.py        # 或任意一个
```

脚本内部用 `__file__` 解析路径，**在哪个目录运行都一样**。
`sys.path` 已自动注入父目录，可直接 `import improved_droplet`。

输出图片写到 `out/`（论文原页与嵌入图在 `out/thesis/`）。

## 脚本清单

### 轨迹与决策（做规则层研究必用）
| 脚本 | 作用 |
|---|---|
| `diag_l2_trace.py` | 打印 l₂ 从指定列出发的**逐格**轨迹：`(r,c)` + `j`/`Q`/`k`/`s` + 动作类型。定位"哪一格发生了非直落"。可传列号：`python diag_l2_trace.py 77 46` |
| `diag_l2_window.py` | 打印**关键格点周围 6×13 的 ink 窗口**（# 墨迹 / 数字=白邻点编号 / X 数字=黑邻点）+ 7 邻点权值表 |
| `diag_paper_vs_patent.py` | **论文 §3.2.1 版（5 邻点）vs 专利 2024 版（7 邻点）**逐行决策对比，找分歧点；并枚举 δ₂ 带内各列的终点 |
| `diag_topology.py` | 打印核心区 **ASCII 墨迹拓扑图**（rows 15-95, cols 50-90）——看"横笔是斜的"这类几何事实最快的方式 |

### 几何与缝隙
| 脚本 | 作用 |
|---|---|
| `diag_gaps.py` | 逐列**渗透深度**（从该列顶部落下能走多深才碰墨）+ 深通道区间 + 叠加标注图 |
| `diag_truth_geom.py` | 在 `p49_img4` 上叠加 10% 网格与候选竖线，肉眼核对锚点位置 |
| `diag_orientation.py` | 核对图像方向与尺寸口径（`c/W` vs `c/(W-1)`），反解真值列 |

### 真值线量测（推翻/确认结论的关键证据）
| 脚本 | 作用 |
|---|---|
| `diag_truth_measure.py` | **从图3-23 四面板分离绿色像素**，逐行量 l₂ 中心列 → 得出四面板终点均为 `c/W=0.5238` |
| `diag_truth_vs_impl.py` | 检查真值线**逐格是否踩在墨迹上**（揭示论文 l₂ 是横切穿越而非绕行） |

### 选优机制判别（2026-09-17 三次复核，**推翻"目标可达"前提**）
| 脚本 | 作用 |
|---|---|
| `diag_l2_selection.py` | **枚举 40 种 (δ₂ 带 × 指标 × tie-break) 组合**，判定"枚举+指标"框架能否产生起点列 77 → **无一命中**；并打印全宽逐列指标表与吸引子分布 |
| `diag_l2_selection2.py` | 对比**论文四面板三元组**（起点列, 中间段列, 终点列）与本实现各起点的三元组 → 本实现的中间段列集合里**根本没有 63**，判定论文那条 l₂ 与不同源 |

> 这两个脚本是本项目**方向性结论**的依据（见 `../../docs/adr/0001`），
> 结论：论文图3-23 的 l₂ 不是"改进滴水算法在 δ₂ 带内枚举选优"的产物。
> 纯只读，不改算法、不污染回归。

### 论文 PDF 提取

| `diag_pdf_extract.py` | 高清渲染指定页 + **导出页内所有嵌入图**（图3-23 四面板就是这样拿到的） |

### 假设判定

|---|---|
| `diag_melt_hypothesis.py` | 判定"熔断斩横笔"假设：把水滴放到横笔正上方看决策 + 统计各列需穿越厚度 |
