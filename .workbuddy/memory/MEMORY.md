## 术语歧义（重灾区，已在 CONTEXT.md 立规）

- **「指标层」≠「度量口径」**：前者指 A/B/C/D 选优，后者指 `c/W` 的定义。
  这两个问题曾被混成一个，导致浪费一轮研究。
- **`j=4` 是"右侧"、`j=5` 是"左侧"**：相对前进方向 g 而言，**不是图像坐标的左右**。
  在 l₁（g 向右）里 j=4 指的是**下方**。
- **「熔断」与「选优」是两件独立的事**：混成一件会在错误方向施工（第二轮教训）。
